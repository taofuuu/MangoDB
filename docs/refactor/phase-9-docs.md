# Phase 9 — Docs

**Status: done.** Snapshot diff empty.

## What was wrong

`apps/mangodb/README.md` described an app that had not existed for some time:

| It said                                              | Actually                                                           |
| ---------------------------------------------------- | ------------------------------------------------------------------ |
| `lib/auth.ts` is the only file that touches storage  | There is no `lib/auth.ts`                                          |
| The token lives in `localStorage` as `mangodb.token` | Nothing is in `localStorage`; the session is an httpOnly cookie    |
| `lib/api.ts` attaches the bearer token               | It does not, and cannot — httpOnly means JS cannot read the cookie |
| Set `NEXT_PUBLIC_API_URL`                            | `API_URL`, server-side, read by `next.config.ts`                   |
| "There is no login page yet"                         | `/login` and `/admin/login`                                        |
| Visit `/dev/session` to get a token                  | Phase 7 deleted that route                                         |

Reading that page top to bottom would have you write a component that stores a
token nothing reads and sends a header nothing checks.

Also fixed:

- The page title was **`Create Next App`** and the description **"Generated by
  create next app"**.
- `app/layout.tsx` carried a commented-out `RootLayout` and two Geist fonts
  that only it referenced. Their CSS variables were already undefined at
  runtime, because `<html>` uses `ibm.className`.
- **`apps/mangodb` had no `.env.example`** while `next.config.ts` reads
  `API_URL`, so there was nothing telling you the variable exists.
- The temporary index on `app/page.tsx` said the certificate page runs on mock
  data (it runs against the API) and pointed at "sample id 1".
- **`CLAUDE.md` gave Sprint 2's tab id as `1160186929`** — that is Sprint 1's.
  The real one is `517739515`, checked by fetching it. **`CLAUDE.md` is
  gitignored**, so that fix is local to this machine; tell the team, or the
  next person reads the wrong sprint.

## Rules this phase leaves behind

1. **A doc that contradicts the code is a bug of the same severity as the
   code being wrong.** Somebody will follow it, and they will be slower than if
   there were no doc at all.
2. **A README is part of the change that invalidates it.** The localStorage
   paragraph outlived the localStorage by several PRs because removing the code
   and correcting the page were never the same task.
3. **Every environment variable is in an `.env.example`.** A variable only the
   code knows about is a variable nobody sets.
4. **A temporary page says it is temporary, and stays true.** A link list
   nobody trusts is worse than no link list.
